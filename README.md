# Auto-Acco-2020

Auto-Acco is a solution for automatically creating accompaniment for vocal performer in real time.

# Installation

Use the package manager [pip](https://pip.pypa.io/en/stable/) to install Auto-Acco-2020.

# Usage

```python
# midi file names
midi_name = "780"
# name to save
audio_name_save = "780"
# audio end time
audio_end_time = 20
```

Change audio_name_save, midi_name, audio_end_time according to your preference.

run auto_combine_v1_micro.py with your midi.

The final result is in auto_accompany folder.
